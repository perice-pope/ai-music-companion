# Testing the music app — quick start 🎵

Hi! This is the easy way to test the app and send feedback. One setup, then just one command —
and it keeps itself up to date automatically.

## First time only (~5 min)

1. Open the **Terminal** app (press `Cmd + Space`, type "Terminal", press Enter).
2. Drag the `install.sh` file from this folder into the Terminal window, then press **Enter**.
   - If it asks for your **Mac password**, type it and press Enter (you won't see it typing — normal).
   - When it asks for a **feedback code**, paste the code your manager sent and press Enter.
3. Wait for **"All set! 🎉"**.

## Every time you test

1. Open **Claude Code**.
2. Type **`/test-app`** and press Enter.
3. Follow along and answer the questions. When it says "All done," your feedback is sent. 💛

You never have to reinstall — it grabs the newest version of the app and the latest questions each
time on its own.

## The "real sound test"

When your manager asks for a real test of **playing music and getting feedback**, type this instead:

```
/test-app desktop
```

This opens the **real app that can hear you and let you upload music**. The **first** time it needs
to get ready and can take **10–30 minutes** — that's normal, just leave it running (grab a coffee ☕).
It will ask to use your **microphone** — click **Allow** — and it'll ask you to hum or play a few
notes. After the first time it's much faster.

If anything looks stuck or confusing, take a screenshot and send it to your manager.
