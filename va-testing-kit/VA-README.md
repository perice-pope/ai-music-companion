# Testing the music app — quick start 🎵

Hi! This is the easy way to test the app and send your feedback. Two steps the first
time, then just one step forever after.

## First time only (about 5 minutes)

1. Open the **Terminal** app (press `Cmd + Space`, type "Terminal", press Enter).
2. Drag the `install.sh` file from this folder into the Terminal window, then press **Enter**.
   - It may ask for your **Mac password** — type it and press Enter (you won't see it typing; that's normal).
   - When it asks for a **feedback code**, paste the code your manager sent you and press Enter.
3. When you see **"All set! 🎉"**, you're done with setup.

## Every time you want to test

1. Open **Claude Code**.
2. Type this and press Enter:

   ```
   /test-app
   ```

3. Follow along! It will open the app in Chrome and ask you a few simple questions.
   Just answer in your own words. When it says **"All done"**, your feedback has been
   sent — that's it. 💛

### If your manager asks for a "real sound test"

Type this instead:

```
/test-app desktop
```

This opens the **real app that can hear you**. The **first** time, it needs to get ready and
can take **10–30 minutes** — that's normal, just leave it running (grab a coffee ☕). It may
ask to use your **microphone** — click **Allow**. After that it works like the normal test.

That's everything. If anything looks stuck or confusing, take a screenshot and send it
to your manager.
