# Musa 2.0.0 — the grounded practice companion

2.0 is the release where Musa goes from "real-time tuner with a canned recap" to a
**practice companion that remembers and understands your sessions**.

## Highlights

- **Sessions now persist.** Every completed session is saved locally (SQLite) —
  duration, instrument, the full AI recap, and the **per-phrase metrics**
  (pitch / cents / timing) behind it — so history, stats, and (opt-in) cloud
  sync finally have something to read.
- **Grounded AI feedback.** The offline recap is generated from your **measured
  fingerprint** (intonation, key/mode, groove/swing, tone) instead of canned
  text — so it varies session to session and tells the truth.
- **Honest "Flavour."** The style read-out is now derived from the reliable
  mode + swing signal (and stays silent when ambiguous) rather than an
  unreliable placeholder corpus.
- **Real rhythm notation.** Imported / transcribed MIDI is now **quantized**
  (grid + rests, with adaptive tuplets and swing) before notation, so scores
  read cleanly instead of as a tied-note soup.
- **Safe schema migrations.** A `PRAGMA user_version` migration framework lets
  the on-disk database evolve forward without losing existing data.

## Breaking change

The practice-session **data model changed substantially**. Sessions persist with
a new schema (per-phrase table + session debug columns via versioned
migrations), and the recap shape gained grounded fields (`fingerprint`,
`flavour`). Databases from 1.x are **migrated forward automatically**, but the
session/recap contract is **not backward-compatible** with 1.x readers.

## What's next

The 2.x roadmap is about turning Musa's live musical perception into magic:
follow-me accompaniment, "hear it fixed" playback, conversational voice
coaching, an adaptive daily plan, progress you can feel — and the data moat:
a real idiom corpus growing toward **song identification**.
